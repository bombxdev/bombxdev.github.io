# GTA Online FAQ (`/gta-online/faq/`)

คำถามที่ผู้เล่นถามบ่อย เขียนด้วยคำของเราเอง แต่ละข้อมี: ผู้เล่นคุยกันเรื่องอะไร, คำอธิบาย, ควรทำอย่างไร,
ระดับความมั่นใจ (Verified / Community consensus / Community opinion / Unconfirmed), แหล่งที่มา และวันที่ตรวจทานล่าสุด

- `data/faq.json` – รายการคำถาม: `id`, หมวด (`cat`), ระดับความมั่นใจ (`conf`), แหล่งที่มา (`sources: [[ชื่อ, url]]`),
  ลิงก์ภายในเว็บ (`link`, ไม่บังคับ) และวันที่ตรวจทาน (`reviewed`)
- `i18n/<code>.json` – ข้อความทั้งหมด 16 ภาษา: `i.<id>.q / .insight / .explain / .rec` (การ์ดชุมชน: `i.<id>.q / .a / .note`) และ UI `f.*`
- `faq.js` – แสดงผล ค้นหา กรองตามหมวด และเปิดคำถามจากลิงก์ `#q-<id>`

เพิ่มคำถามใหม่: ใส่รายการใน `data/faq.json` + ข้อความ 4 คีย์ในทุกภาษา แล้วเปลี่ยน `reviewed` และเลข `?v=` ใน `index.html`

## แหล่งข้อมูล

- **การ์ด `r0xx` (41 ใบ)** มาจากไฟล์ research handoff (`gtaonline_faq_th.json`, ตรวจทาน 9 พ.ย. 2026) ซึ่งสรุปด้วยคำใหม่จาก FAQ
  และคำตอบที่คัดเลือกในเธรด "Simple and Frequently Asked Question Thread" ของ r/gtaonline โดยผู้ค้นคว้าที่เปิดเธรดได้
  (เราเปิด Reddit จากเครื่องที่สร้างหน้าไม่ได้) ฟิลด์ `ref` = id เดิมใน handoff (GTAFAQ-xxx) ข้อความไทยใช้ตามไฟล์ อีก 15 ภาษาแปลจากภาษาอังกฤษ
  - ป้าย: `thread` = FAQ จากชุมชน, `reply` = คำแนะนำจากผู้เล่น, `opinion` = ความเห็นของผู้เล่น (ไม่มีการ์ดไหนอ้างว่าเป็นข้อมูลทางการของ Rockstar)
  - `vol`: `change` / `event` / `platform` = ความเสี่ยงที่ข้อมูลจะล้าสมัย
  - รายการที่ `publish_recommended=false` (อีเวนต์เก่าและเรื่องถกเถียง: GTAFAQ-039–042, 045) ไม่แสดง ระบุไว้ใน `handoff.archived`
  - GTAFAQ-002 (ย้ายตัวละคร) รวมเข้ากับการ์ด `migrate` ที่มีอยู่ (เพิ่มเธรดเป็นแหล่งที่มา)
- **การ์ดอื่น 12 ใบ** (รวม Dr. Dre Contract, Cluckin' Bell Farm Raid และ KnoWay Out ที่ FAQ ของเธรดพูดถึงแต่ handoff ไม่ได้อธิบาย)
  เขียนจากหน้าทางการของ Rockstar และคู่มือสาธารณะที่ลิงก์ไว้ใต้แต่ละคำถาม (อ่านผ่านผลการค้นหาเว็บ)
- `related` = ลิงก์ "ดูเพิ่มเติม" ไปการ์ดอื่น
  ตัวเลขเงินจากคู่มือเป็นค่าประมาณ อาจเปลี่ยนตามอัปเดตเกม
