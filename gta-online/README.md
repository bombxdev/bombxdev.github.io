# GTAO OS (`/gta-online/`)

หน้าเมนูรวมของเครื่องมือ GTA Online ใช้งานที่ `https://bombxdev.github.io/gta-online/` หน้าตาแบบเดสก์ท็อป OS:

- หน้าบูต (ครั้งแรกของแต่ละแท็บ ข้ามได้ถ้าเปิด "ลดการเคลื่อนไหว" ในเครื่อง)
- แถบเมนูด้านบน: ปุ่ม ◈ GTAO**OS** (เมนูเริ่ม + ค้นหาแอปและทางลัด), ชื่อแอปที่เปิดอยู่, เวลาในเกม, เวลาที่เหลือก่อนรีเซ็ตรายวัน, ภาษา, นาฬิกา
- ไอคอนแอปบนเดสก์ท็อป: คลิก = เปิดหน้าต่างอธิบายพร้อมทางลัด, ดับเบิลคลิก = เปิดแอปเลย
  หน้าต่างลากได้ ขยายเต็มจอได้ (ปุ่มเขียว / ดับเบิลคลิกแถบหัว) ปิดด้วยปุ่มแดงหรือ Esc
- Dock ด้านล่าง: เปิดแอปโดยตรง (จุดใต้ไอคอน = หน้าต่างนั้นเปิดอยู่)
- วิดเจ็ต: นาฬิกาในเกม และ "วันนี้" (Gun Van, Street Dealers ลิงก์ไปจุดบนแผนที่) คำนวณด้วย `map/daily.js`
  และข้อมูล `map/data/*.json` ชุดเดียวกับหน้าแผนที่ (ผลตรงกัน)
- จอเล็ก (≤ 760px): เป็นหน้าแอปแบบมือถือ หน้าต่างเปิดเต็มจอ

แอปทั้งหมดอยู่ใน `APPS` ใน `portal.js` (เพิ่มแอปใหม่: ใส่ id, ลิงก์, สีไอคอน, รูป SVG ใน `ICONS` และข้อความ `p.<id>`, `p.<id>Sub`, `p.<id>F1..` ใน `i18n/`)
ไอคอนและภาพเมืองเป็นงานวาดใหม่ทั้งหมด ไม่ได้ใช้โลโก้หรือภาพจากเกม

## ภาษา

16 ภาษาแบบเดียวกับหน้าอื่น (`map/i18n.js`, ไฟล์ข้อความใน `i18n/`) ภาษาที่เลือกใช้ร่วมกับแผนที่และหน้าวางแผนปล้น (`gtaomap.lang`)
หน้าแผนที่และหน้าวางแผนปล้นมีปุ่ม 🏠 กลับมาหน้านี้

## ก่อน deploy

เปลี่ยน `data-app-version` และ `?v=` ใน `index.html` (ไฟล์ข้อมูลโหลดด้วยเลขนี้)
